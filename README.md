#### Featured project

**[Zetapro](https://github.com/amirkhan0725/zetapro)** is a mental-math trainer I built while preparing for trading interviews. It's a Zetamac-style speed game plus an Optiver-style “80 in 8” that times every answer, shows which kinds of problems cost you the most time, and turns those weak spots into targeted drills.

- [Play it in your browser](https://amirkhan0725.github.io/zetapro/) (works on phones too) or [download it for Windows](https://github.com/amirkhan0725/zetapro/releases/latest)
- Plain JavaScript, Electron and Firebase, with optional sign-in to sync across devices
